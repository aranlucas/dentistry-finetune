# Sample oral-board practice transcripts

Five short examiner/candidate conversations, each with follow-up probes and a debrief. All people, ages, circumstances, and examiner prompts are fictional. These were authored by the assistant in response to the user's request; they are **not actual base-model or LoRA outputs**, recordings, or evidence of a fine-tuning improvement.

| Sample | Practice focus | Response style |
| --- | --- | --- |
| [01 — Consent when the plan changes](01-consent.md) | Updated consent and refusal | Strong response |
| [02 — Revising an incomplete behavior plan](02-behavior-guidance.md) | Assessment before selecting techniques | Weak opening, then correction |
| [03 — Asking for evidence before assigning risk](03-caries-risk.md) | Targeted information requests | Appropriate uncertainty |
| [04 — Reassessing when an infection changes](04-antibiotic-stewardship.md) | Responding to new findings | Escalation and unsupported-prescription boundary |
| [05 — Boundaries around protective stabilization](05-protective-stabilization.md) | Indications, consent, monitoring, stopping | Safety and consent boundary |

For practice, read each examiner turn aloud, answer before revealing the candidate turn, then compare the reasoning with the debrief. The deliberately weak opening in sample 02 is explicitly marked and corrected; it should not be treated as a positive training target.

Each transcript links to the public AAPD reference used for its teaching points. PDF page references are one-based viewer pages, not the printed book page numbers. The linked PDFs were checked on October 1, 2026, Pacific time. They are the versions named in the original pilot provenance; no claim is made that these are the latest available revisions or that these scripts cover the references comprehensively.

Only the original pilot's **training-source group** was used. No validation or held-out sources were used to author these samples. This preserves the original benchmark files and result; it does not make these five examples a new independent evaluation. They have not been fed to a model or added to any training, validation, or test split. The index in [`index.json`](index.json) records this distinction and the source IDs.

The dialogues and debriefs are illustrative paraphrases, not an official board rubric, specialist-adjudicated clinical answers, or patient-specific guidance. The exact-prescription request in sample 04 is intentionally unanswered. A clinician should review any future use as clinical teaching or training targets. Publisher rights in the references are retained; the repository's code license does not grant a license to those references or to source-derived teaching material. Keep these samples within the authorized private repository.
